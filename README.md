# Тренажёр ЦТ и ЦЭ (Telegram Mini App)

Python 3.10+. Сервер: FastAPI + SQLite. Интерфейс: webapp/index.html. Бот: bot.py (aiogram 3).

## Запуск локально (без Telegram)
    python -m venv .venv
    .venv\Scripts\activate          # Linux/macOS: source .venv/bin/activate
    pip install -r requirements.txt
    $env:DEV="1"                    # PowerShell (терминал PyCharm). cmd: set DEV=1. Linux/macOS: export DEV=1
    uvicorn server.main:app --reload
Откройте http://localhost:8000 (пользователь «Dev»).

## Локальный запуск Docker + Telegram
Скопируйте `.env.example` в `.env` и укажите в нём `BOT_TOKEN` от `@BotFather` (не отправляйте токен в чат и не добавляйте `.env` в репозиторий). Запустите весь локальный стек одной командой:

    docker compose -f docker-compose.dev.yml up --build

Compose запускает веб, Cloudflare Quick Tunnel и бота. Публичный HTTPS URL создаётся автоматически и передаётся боту; если Tunnel выдаст новый URL после перезапуска, бот перезапустится с новой ссылкой. Оставьте Compose запущенным, иначе временная ссылка Cloudflare перестанет работать. Приложение доступно локально на http://localhost:8000. Остановка: `docker compose -f docker-compose.dev.yml down`; том `app_data` сохраняется.
### Локальная админ-панель
В dev-режиме страница доступна по http://localhost:8000/admin, а admin API дополнительно защищён случайным ключом из `.env.admin`. Скопируйте значение `ADMIN_PANEL_TOKEN` оттуда в поле входа. Порт привязан к `127.0.0.1`, сервер также принимает запросы только с `localhost`/`127.0.0.1`; `.env.admin` исключён из Git и Docker build context. Не публикуйте и не передавайте ключ. Не направляйте `/admin` через публичный reverse proxy.

## Публичный запуск Telegram Mini App
Для запуска «для всех» нужен VPS с публичным IPv4, доменом и ботом, созданным через `@BotFather`. В DNS создай A-запись домена на IP VPS. На сервере должны быть установлены Docker Engine и Docker Compose plugin; открой входящие порты 80 и 443.

1. Скопируй проект на VPS и перейди в его каталог.
2. Создай `.env` из шаблона `deploy/env.example`: `cp deploy/env.example .env` (в PowerShell: `Copy-Item deploy/env.example .env`). Укажи настоящий `BOT_TOKEN`, `BOT_USERNAME` без `@`, свой Telegram ID в `ADMIN_ID` и домен в `DOMAIN`. Токен вводи только в `.env` на сервере, не отправляй его в чат и не добавляй в репозиторий.
3. В `@BotFather` выполни `/setdomain` и укажи тот же домен, например `learn.example.com` без `https://`.
4. Запусти сервисы: `docker compose up -d --build`.
5. Проверь состояние: `docker compose ps` и `docker compose logs -f web bot caddy`. Открой чат с ботом и нажми «Начать учиться» или кнопку Mini App в меню.

Caddy автоматически получает и продлевает TLS-сертификат. Наружу опубликованы только 80/443; API доступно через HTTPS-домен. SQLite хранится в Docker volume `app_data` и переживает пересоздание контейнеров. Для резервной копии используй `docker compose exec web python -c "import sqlite3; a=sqlite3.connect('/data/app.db'); b=sqlite3.connect('/tmp/app-backup.db'); a.backup(b); b.close(); a.close()"`, затем скопируй файл из контейнера командой `docker compose cp web:/tmp/app-backup.db ./app-backup.db`.

Не включай `DEV=1` на сервере. Для обновления кода выполни `docker compose up -d --build`; не удаляй volume `app_data`, иначе потеряешь прогресс и платежные записи.

## Задания
Кладите JSON-файлы в папку tasks (образец: tasks/sample.json) и перезапускайте сервер: задания загружаются по id.
Показываются только задания с `"verified": true`: выставляйте его после ручной проверки ответа и разбора.
Типы: `choice` (answer = номер варианта с нуля) и `number` (answer = число). Формулы: `$...$` (KaTeX).

## Что уже есть
XP, серия дней и щиты серии, монеты и магазин, цель дня, 5 сердец (+1 за 30 минут), 7 наград,
недельный топ, бонус за сессию без ошибок.

## Что добавлено во второй версии
- Архив ошибок с короткими подборками до 10 заданий. Ошибочные ответы остаются в очереди; после правильных повторов через 1, 3, 7 и 14 дней задание закрывается, но возвращается для закрепления через 30, 60 и 90 дней. Ошибка на любом этапе сбрасывает её в начало цикла. Параметры: `error_steps_days` и `error_reinforcement_days`. В режиме DEV «день» = 1 минута.
- Ловушки: в задании поле `distractors` (номер неверного варианта -> `trap` и `why`), показывается после ошибки.
- По каждому предмету можно пройти отдельную диагностику до 10 заданий, по одному из разных тем. Исходный ориентир 0-100 сохраняется отдельно; правильные и неправильные ответы в тренировках, повторах и экзаменах плавно двигают его на 2.5% оставшегося расстояния к 100 или 0. Это внутренняя оценка тренажёра, не официальный прогноз экзамена.
- Схема SQLite обновляется автоматически при запуске; не удаляйте `app.db`, если нужно сохранить прогресс пользователей.

- Раздел «Темы»: статус и точность по каждой теме, тренировка по теме и предметная диагностика; ошибки уходят в архив.
- Карточка дня на главной: правила и факты лежат в content/cards.json.

- Типы заданий: choice, multi (несколько верных номеров), nums (номера цифрами), match (А2Б1В3), text (слово; е и ё равны), общий текст к группе заданий (поле `passage`).
- Импорт сборников: `python tools/import_json.py путь_к_json_или_папке` (формат id/part/task/options/answer/common_text). Печатает отчёт; без `--verified` задания скрыты.

- Пояснения и темы через Gemini: `$env:GEMINI_API_KEY="..."` и `python tools/enrich.py --limit 8` (потом без --limit). Результат пишется в tasks/*.json как черновик ("ai": "draft"); сомнительные ключи скрываются с review_note.

- Пояснения из AI Studio: в JSON сборника у каждого задания можно задать `explanation` (1-3 короткие строки), `topic` и `doubt` (если ИИ сомневается в ключе, задание скрывается). `import_json.py` их подхватывает, пояснение показывается после ответа и при верном, и при неверном.

## Третья версия: сборники, экзамен, оплата
**Условия меняются в `settings.json`** (применяются сразу, без перезапуска): пробный срок `trial_days`, цена `price_stars`, срок оплаты `paid_days` (0 = навсегда), `paywall_enabled: false` отключает оплату совсем, сердца `hearts_enabled` (сейчас выключены), подсказки `hints_enabled` / `hint_cost_coins` / `hints_in_exam`, время экзамена `exam_minutes`, баллы `exam_points`, шкала `exam_scale` ([[первичный, тестовый], ...]; пусто = линейно до 100), XP.

**Сборники.** Один файл на год в папке `tasks`: `2017.json` = `{"year":2017,"variants":[{variant_number, reading_text, tasks:[...]}, ...]}`. Новый вариант от AI Studio можно дописать в тот же файл: либо внутрь `variants`, либо просто ниже предыдущего `{...}` (подряд идущие объекты тоже читаются). Проверка файла: `python -m server.sborniki` (покажет ошибку JSON с местом, пропуски в нумерации, скрытые из-за `doubt` задания). После правки перезапустите сервер. Необязательное поле задания `hints: ["своя подсказка"]`.
Плоские списки (результат `tools/import_json.py`) тоже работают, но для сборников он больше не нужен. Старый `tasks/rus-2017.json` удалите, иначе задания задвоятся (id теперь `2017-v1-A1`).

**Режимы.** Тренировка по варианту (по порядку, подсказки: тема и формат -> свои подсказки -> убрать два лишних -> разбор). Экзамен: таймер, навигация по номерам, ответы сохраняются на сервере (можно закрыть и продолжить), подсказок нет. После экзамена: примерный балл, части А и В, слабые темы, разбор каждого задания, «Работа над ошибками» (тест из неверных). Все ошибки и пропуски идут в общий архив с повторением. Если до ответа открыт разбор, задание не засчитывается (`reveal_counts_as_miss`).

**Оплата Stars.** Счёт создаёт сервер (`createInvoiceLink`, валюта XTR), доступ выдаёт только бот после `successful_payment` (общий app.db). Запускайте и сервер, и бот. `/paysupport` есть, возврат: `/refund <user_id> <charge_id>` (нужна переменная `ADMIN_ID`). В DEV без токена «оплата» проходит сразу. Существующим пользователям пробный срок считается с момента обновления.

**Отчёты о новых пользователях.** Укажите свой числовой Telegram ID в `ADMIN_ID` в `.env`; узнать его можно командой `/myid` у бота. При первой регистрации сервер отправит на этот аккаунт имя, username (если он задан) и Telegram ID. Нужно предварительно открыть чат с ботом и нажать Start, иначе Telegram не позволит боту начать переписку.

Stars зачисляются в баланс мини-приложения, доступный Telegram-аккаунту, который владеет ботом; это не моментальное зачисление денег на банковский или личный баланс. По действующим правилам Telegram Stars можно потратить на рекламу приложения или запросить вознаграждение через Fragment. Telegram указывает текущую расчётную стоимость вознаграждения $0.013 за Star; Stars могут стать доступны для вознаграждения не сразу, а в течение 21 дня. Доступность Fragment зависит от страны и его условий, курс может изменяться. Доходы и налоги необходимо учитывать самостоятельно.

## Четвёртая версия
- **Предмет** задаёт поле `"subject"` в начале файла года (`rus`, `math`, `phys`, `chem`, `bio`, `hist`; можно и в отдельном варианте). Без поля = `rus`. Для нового предмета добавьте название в `NAMES` в webapp/index.html (строка с `const NAMES`).
- **Ошибки.** Вкладка «Ошибки» с числом в нижнем меню и плашкой на главной показывает первичную очередь и созревшие повторы для закрепления. Короткие тесты содержат до 10 заданий; неверный ответ возвращает вопрос в текущую очередь (до 5 раз за сессию). После цикла `error_steps_days` закрытые ошибки возвращаются по графику `error_reinforcement_days`; повторная ошибка начинает цикл заново. Напоминания бота включают и такие созревшие повторы.
- **Бесплатная версия** (после пробного срока) настраивается блоком `free_plan` в settings.json: `daily_tasks`, `sborniki`, `exam`, `errors`, `hints`, `score`. Ошибки в бесплатной версии записываются, после оплаты всё на месте.
- **Поделиться результатом** после экзамена и **приглашение друга**: задайте переменную `BOT_USERNAME` (без @) для сервера; бонус `referral_bonus_days` обоим.
- **Напоминания ботом** о непроработанных ошибках (`reminder_enabled`, `reminder_hour`, по Минску, раз в сутки).
- **Жалобы на задания**: кнопка «Ошибка в задании?» пишет в таблицу `reports` и присылает вам сообщение, если задан `ADMIN_ID`.
- Из слабых тем в итогах экзамена можно сразу запустить тренировку.

## Чего нет
ИИ-разбора, дуэлей и админ-панели. XP за задание начисляется один раз в день, бонус идеальной сессии — один раз в день. Настоящая шкала баллов ЦТ и веса заданий не заданы: проставьте `exam_points` и `exam_scale`.

## Безопасная эксплуатация
- Не включайте `DEV=1` на публичном сервере: этот режим отключает проверку Telegram и использует пользователя №1.
- Храните `BOT_TOKEN` и ключи интеграций только в переменных окружения/секретах платформы. Не публикуйте `app.db`, в ней есть Telegram ID, имена и учебная история.
- Публикуйте приложение только через HTTPS и ограничьте доступ к серверу, SQLite-файлу и `settings.json`.
- Запустить регрессионные проверки: `python -m unittest discover -s tests -v`.
